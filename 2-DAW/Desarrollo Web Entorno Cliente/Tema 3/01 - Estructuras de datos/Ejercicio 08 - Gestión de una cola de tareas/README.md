# Ejercicio 8. Gestión de una cola de tareas
## Preguntas y respuestas

### 1. ¿Qué documento se procesa primero?
Respuesta: Se procesa el documento A, por ser el primero en insertarse

### 2. ¿Qué método permite retirar el primer elemento del array?
Respuesta: El método es el shift(), elimina el elemento en el índice 0 y mueve al resto hacia la izquierda para que no se quede el hueco vacío

### 3. ¿Por qué esta estructura representa una cola y no una pila?
Respuesta: Porque esto es un FIFO, el primero en entrar es el primero en salir, una pila es un LIFO, donde el último en entrar es el primero en salir
