# Ejercicio 4. Clasificar estructuras de datos
## Preguntas y respuestas
### 1. ¿Qué estructura usarías para guardar las notas de cinco exámenes en el orden en que se realizaron? Justifica.
**Respuesta**: Usaría un array ya que es lo mejor para guardar las notas de los exámenes en orden cronológico y te deja meter notas duplicadas (Ej: 2 alumnos que sacan un 0 o 2 que sacan un 10)

### 2. ¿Qué estructura usarías para guardar nombres de usuario sin repetir? Justifica.

Respuesta: Usaría un set ya que garantiza que no haya duplicidad y permite verificar si existe un usuario de forma más rápida

### 3. ¿Qué estructura usarías para asociar el nombre de cada alumno con su nota? Justifica.

Respuesta: Usaría un map porque deja almacenar información en pares de clave-valor, usando el nombre del alumno como clave unica y la nota como valor asociado

### 4. ¿Qué estructura usarías para guardar códigos de productos evitando duplicados? Justifica.

Respuesta: Usaría un set ya que no deja que haya duplicidad

### 5. ¿Qué estructura usarías para guardar el nombre de una asignatura y su número de horas? Justifica.

Respuesta: Usaría un Map para asociar el nombre de la asignatura como clave y las horas como valor

### 6. ¿Qué estructura usarías para guardar los nombres de los tres últimos archivos abiertos conservando su orden? Justifica.

Respuesta: Usaría un Array ya que permite meter los nuevos archivos al principio o al final conservando el orden de apertura y puede también limitar el tamaño a 3 elementos

### 7. ¿Qué diferencia principal hay entre un array y un Set?

Respuesta:
- **Array**: Mantiene un órden por índice y deja poner elementos duplicados
- **Set**: Deja almacenar elementos únicos sin duplicidad y no garantiza el acceso directo por índice

### 8. ¿Qué diferencia principal hay entre un Set y un Map?

Respuesta:
- **Set**: Guarda una colecció de valores únicos e individuales 
- **Map**: Almacena asociaciones de pares clave-valor donde cada clave tiene que ser única
