# Ejercicio 3. Predecir el resultado de un programa
## Preguntas y respuestas
### 1. ¿Qué elementos contiene el array después de cada operación?
**Respuesta**:
```js
let numeros = [10, 20, 30]; // Tiene 3 elementos de base
numeros.push(40); // Tiene 4 elementos (10, 20, 30 y 40)
numeros.unshift(5); // Tiene 5 elementos (5, 10, 20, 30 y 40)
numeros.pop(); // Tiene 4 elementos (5, 10, 20, 30)
```

### 2. ¿Qué muestra la primera instrucción console.log()?
**Respuesta**:
```js
console.log(numeros); // Muestra todos los elementos del array números
```

### 3. ¿Qué muestra la segunda?
**Respuesta**:
```js
console.log(numeros[0]); // Muestra la posición 0 del array que es 5 (Primera posición)
```

### 4. ¿Qué muestra la tercera?
**Respuesta**:
```js
console.log(numeros[2]); // Muestra la posición 2 del array que es 20 (Tercera posición)
```
