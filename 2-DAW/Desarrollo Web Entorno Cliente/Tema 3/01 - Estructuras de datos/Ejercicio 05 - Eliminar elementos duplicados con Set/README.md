# Ejercicio 5. Eliminar elementos duplicados con Set
### Código de partida
```js
let asistentes = ["Ana", "Luis", "Ana", "Marta", "Luis", "Pedro"];
```
## Preguntas y respuestas
### 1. ¿Cuántos nombres hay en el array original?
Respuesta: Hay 6 nombres en total 

### 2. ¿Cuántos nombres diferentes hay?
Respuesta: Hay 4 nombres diferentes en el array, y pasan a ser 5 cuando metes a Sonia en el set

### 3. ¿Por qué Ana no aparece duplicada en el conjunto?
Respuesta: Por que en un Set no se permite duplicidad de elementos, aunque intentes añadirla de vuelta, no va a dejarte
