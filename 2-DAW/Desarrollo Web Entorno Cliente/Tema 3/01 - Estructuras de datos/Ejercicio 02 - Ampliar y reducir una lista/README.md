# Ejercicio 2. Ampliar y reducir una lista
## Preguntas y respuestas
### 1. ¿Qué métodos has utilizado para añadir elementos?
**Respuesta**: Para añadir he usado push y unshift
```js
productos.push("Impresora");
productos.unshift("Altavoces");
```

### 2. ¿Qué métodos has utilizado para eliminarlos?
**Respuesta**: He usado pop y shift
```js
productos.pop();
productos.shift();
```

### 3. ¿Qué diferencia hay entre push() y unshift()?
**Respuesta**:
- **Push**: Lo que haces es añadir el objeto definido entre paréntesis al final del array (Última posición).
- **Shift**: Lo que hace es añadir el objeto entre paréntesis al inicio del array

### 4. ¿Qué diferencia hay entre pop() y shift()?
**Respuesta**:
- **Pop**: Quita el objeto en la última posición del array
- **Shift**: Quita el objeto en la primera posición del array
