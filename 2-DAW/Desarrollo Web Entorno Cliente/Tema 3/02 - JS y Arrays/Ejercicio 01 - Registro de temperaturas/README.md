# Ejercicio 1. Registro de temperaturas

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1535699)

## Enunciado

Una estación meteorológica registra las temperaturas de una jornada.

### Código de partida

```js
const temperaturas = [18.5, 21, 23.5, 19, 16, 25, 22];
```

### Tareas y condiciones

1. Muestra todas las temperaturas con un for tradicional y después con for...of.
2. Calcula la media sin utilizar reduce().
3. Obtén un array con las temperaturas superiores a la media.
4. Crea una copia y añade una nueva temperatura al principio y otra al final sin modificar el original.
5. Muestra la tercera y la última temperatura usando dos formas distintas de acceso.
6. Comprueba temperaturas.at(-2).
