# Ejercicio 6. Modificación controlada de un inventario

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1535699)

## Enunciado

Trabaja con el inventario proporcionado conservando intacto el array original.

### Código de partida

```js
const stock = [12, 0, 5, 3, 0, 18, 2];
```

### Tareas y condiciones

1. Muestra las posiciones con stock cero.
2. Cuenta cuántos productos están agotados.
3. Crea una copia y aumenta en 5 el stock de los agotados.
4. Sustituye por cero los valores negativos de una segunda copia.
5. Comprueba que el original no ha cambiado.
6. Explica modificar stock[i] frente a const copia = stock.
