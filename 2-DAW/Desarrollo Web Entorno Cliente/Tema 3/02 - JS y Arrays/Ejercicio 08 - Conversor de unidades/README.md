# Ejercicio 8. Conversor de unidades

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1535699)

## Enunciado

Convierte las distancias en kilómetros a metros y compara distintas formas de transformar el array.

### Código de partida

```js
const distanciasKm = [1.5, 3, 7.2, 10, 0.8];
```

### Tareas y condiciones

1. Convierte las distancias a metros con un bucle.
2. Repite con map().
3. Guarda los resultados en variables diferentes.
4. Comprueba que los arrays tienen el mismo contenido.
5. Comprueba que el original permanece intacto.
6. Repite la transformación con una función flecha.
