# Ejercicio 5. Analizador de temperaturas

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1535699)

## Enunciado

Recorre el array de temperaturas y calcula los datos solicitados mediante acumuladores y un bucle.

### Código de partida

```js
const temperaturas = [18, 22, 31, 27, 14, 35, 29, 12, 30];
```

### Tareas y condiciones

1. Cuenta temperaturas inferiores a 20 °C.
2. Cuenta temperaturas entre 20 y 30 °C incluidos.
3. Cuenta temperaturas superiores a 30 °C.
4. Calcula la máxima y la mínima.
5. Comprueba si existe alguna superior a 40 °C.
6. Usa acumuladores y un bucle; no uses filter(), map(), reduce(), Math.max() ni Math.min().
7. Reto: repite con for...of y compara.
