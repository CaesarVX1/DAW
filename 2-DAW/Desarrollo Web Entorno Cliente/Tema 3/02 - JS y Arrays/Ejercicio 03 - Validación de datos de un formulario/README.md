## Enunciado

Un formulario web recibe una edad y una nota como texto, junto con la aceptación de condiciones.

### Código de partida

```js
const edadTexto = "17";
const notaTexto = "6.5";
const aceptaCondiciones = true;
```

### Tareas y condiciones

1. Muestra el tipo de cada variable con typeof.
2. Convierte la edad a entero y la nota a decimal.
3. Comprueba si la edad es igual o superior a 18.
4. Comprueba si la nota está entre 0 y 10 incluidos.
5. Determina si puede enviarse: edad válida, nota válida y aceptación de condiciones.
6. Repite las comprobaciones con "diecisiete" como edad y explica los resultados.
