# Ejercicio 7. Matriz

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1535699)

## Enunciado

Cada fila representa un aula y cada columna un tipo de incidencia.

### Código de partida

```js
const incidencias = [[0, 2, 1, 0], [3, 0, 0, 1], [0, 1, 4, 2]];
```

### Tareas y condiciones

1. Muestra cada valor con fila y columna.
2. Calcula el total por aula.
3. Calcula el total por tipo de incidencia.
4. Localiza el aula con más incidencias.
5. Cuenta posiciones con un valor superior a 2.
6. Añade una nueva fila y recalcula los totales.
