# Ejercicio 2. Bucle de arrays

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1535699)

## Enunciado

Una instalación dispone de varios equipos con distintas potencias. Todos funcionan durante las mismas horas.

### Código de partida

```js
const potencias = [120, 250, 80, 450, 150];
const horas = 6;
const precioKWh = 0.18;
```

### Tareas y condiciones

1. Calcula el consumo diario de cada equipo, suponiendo las mismas horas de funcionamiento.
2. Calcula el coste diario de cada equipo.
3. Muestra por consola qué equipos consumen más de 1 kWh al día.
4. Indica el coste total de todos los equipos.
5. Comenta las operaciones y decisiones.
6. Condición: utiliza for e if. No utilices map() ni reduce().

Este ejercicio no incluye preguntas teóricas adicionales.
