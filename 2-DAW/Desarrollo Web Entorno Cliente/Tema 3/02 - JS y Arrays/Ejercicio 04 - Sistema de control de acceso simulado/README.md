## Enunciado

### Código de partida


1. Normaliza el nombre para evitar diferencias entre mayúsculas y minúsculas.
2. Comprueba si el usuario está registrado.
3. Muestra un mensaje distinto para cada causa de denegación.
4. Declara una variable dentro de un bloque y comprueba su ámbito.
5. Modifica los datos para probar todos los resultados.
6. Condición: usa operadores lógicos, includes() y bloques if...else.
