# Ejercicio 1. Calculadora de precios

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1536681)

## Enunciado

Una tienda en línea necesita calcular el precio final de sus productos aplicando un descuento porcentual.

### Tareas y condiciones

1. Declara calcularPrecioFinal(precio, descuento) y devuelve el precio con descuento porcentual.
2. Prueba tres productos; crea otra versión flecha y compara.
3. No escribas directamente el resultado ni guardes los parámetros en variables globales.
