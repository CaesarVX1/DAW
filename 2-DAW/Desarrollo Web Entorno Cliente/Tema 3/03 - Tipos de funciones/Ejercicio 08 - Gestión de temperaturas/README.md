# Ejercicio 8. Gestión de temperaturas

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1536681)

## Enunciado

Una estación meteorológica almacena las temperaturas registradas durante varios días en un array.

### Código de partida

```js
const temperaturas = [18.5, 21, 19.2, 25.4, 17.8];
```

### Tareas y condiciones

1. Crea temperaturas con 18.5, 21, 19.2, 25.4 y 17.8.
2. Muestra longitud, primera y última por índices; cambia tercer día a 20.
3. Añade al final, elimina primera, recorre y muestra.
4. Explica acceso fuera de rango; modifica una copia y comprueba el original.
