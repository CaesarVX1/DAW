## Enunciado

Una aplicación debe ejecutar distintas operaciones matemáticas utilizando una única función de procesamiento.

### Tareas y condiciones

1. Define sumar, restar, multiplicar y procesarOperacion mediante funciones flecha.
2. procesarOperacion recibe dos números y una función, la ejecuta y devuelve el resultado.
3. Prueba las operaciones con los mismos números y añade potencia con Math.pow.
4. El enunciado dice "cuatro operaciones" pero inicialmente enumera tres; conserva esta observación y consulta al profesor si hace falta otra.
5. Explica función como argumento frente al resultado de llamarla.
