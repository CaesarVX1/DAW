# Ejercicio 10. Informe de productos de una tienda

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1536681)

## Enunciado

Una tienda almacena precios en un array y necesita generar información para su página web. El enunciado indica reutilizar el array del ejercicio anterior.

### Código de partida

```js
const notas = [4.5, 7, 8.25, 3.75, 9, 6.5, 5, 2.5];
```

### Tareas y condiciones

1. El enunciado pide reutilizar el array del ejercicio anterior aunque aquel contiene notas. Reutiliza esos datos según indica Moodle y consulta al profesor si desea otros precios.
2. Crea funciones para incrementar precios 10 %, seleccionar > 30, total, media y cantidad >= 20.
3. Utiliza map, filter, reduce y callbacks flecha. Evita repetir cálculos.
4. Muestra resultados, comprueba original intacto y explica transformar, seleccionar y agregar.
