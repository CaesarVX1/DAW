# Ejercicio 9. Análisis de notas de un grupo

[Enunciado en Moodle](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1536681)

## Enunciado

Un profesor almacena las calificaciones de su grupo en un array y necesita generar un resumen de los resultados.

### Código de partida

```js
const notas = [4.5, 7, 8.25, 3.75, 9, 6.5, 5, 2.5];
```

### Tareas y condiciones

1. Implementa obtenerNotaMaxima, obtenerNotaMinima, calcularMedia y contarAprobados (>= 5).
2. Usa Math.max y Math.min adecuadamente y callbacks flecha.
3. Muestra los cuatro resultados y comprueba que no cambia el original.
4. Explica obtener una nota frente a agregar la colección.
