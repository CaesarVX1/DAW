# Ejercicio 2. Menú con anidamiento

## Enunciado

- Usa el `nav` del enunciado. Pon fondo y relleno al menú, quita los márgenes, el relleno y los marcadores de la lista, y coloca los enlaces en horizontal.
- Quita el subrayado de los enlaces y cambia su color con `&:hover`. Escribe los selectores anidados en `menu.scss`.
- Compila el SCSS y compara los selectores. Entrega el HTML, el SCSS, el CSS y una captura.
