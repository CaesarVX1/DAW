# Ejercicio 5. Tarjetas de contenido

## Enunciado

- Crea el mixin `tarjeta` con parámetros y valores por defecto para el fondo, color y grosor del borde, radio, relleno y sombra.
- Aplica el mixin a las clases de noticia, producto y artículo. Coloca dos filas de tres tarjetas en ese orden.
- Comprueba que el CSS compilado contiene las propiedades de los tres tipos de tarjeta.
