# Ejercicio 1. Sistema de diseño con variables

## Enunciado

- Declara `$color-primario`, `$color-secundario`, `$color-fondo` y `$fuente-base`.
- Usa las variables en `body`, `h1` y `.btn`. Cambia el color primario y comprueba que se actualiza donde lo has usado.
- Entrega el SCSS, el CSS compilado y una captura.
