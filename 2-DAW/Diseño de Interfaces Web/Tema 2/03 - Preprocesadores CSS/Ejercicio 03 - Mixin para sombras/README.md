# Ejercicio 3. Mixin para sombras

## Enunciado

- Crea el mixin `box-shadow` con los parámetros `$x`, `$y`, `$blur`, `$spread` y `$color`. Usa los valores por defecto `0`, `0`, `0`, `0` y `black`.
- Aplícalo a `.card` con `2px, 2px, 5px, 1px, #999`, a `.button` con `0, 0, 3px, 0, #333` y a `.alert` sin pasar argumentos.
- Comprueba el CSS generado en Sass Playground. Entrega el SCSS.
