# Ejercicio 4. Mixin con &

## Enunciado

- Reproduce nueve botones en tres filas de color azul, verde y azul oscuro. Usa las variantes primario con fondo de color, secundario con borde de 4 px y terciario con solo texto de color.
- Define las variables `$blue`, `$green` y `$navy`. Usa un único mixin `button-style` con fondo, color de texto, borde y radio.
- Organiza las variantes con anidamiento y `&`. Usa flexbox para las filas y aplica el relleno, el tamaño y grosor de letra, el cursor y el ancho mínimo indicados.
