# Ejercicio 2. Primera hoja de estilos externa

## Enunciado

Crea una página web sobre un centro educativo utilizando dos archivos (puedes usar el HTML que hayas creado del ejercicio 1):

- `ejercicio2.html`
- `estilos.css`

La página debe incluir un título principal, dos subtítulos y cuatro párrafos.

Define los siguientes estilos en `estilos.css`:

- El fondo de toda la página será gris claro (`#f2f2f2`).
- La fuente general será Arial, con una alternativa genérica `sans-serif`.
- El título principal será azul oscuro, tendrá un tamaño de 32 px y estará centrado.
- Los subtítulos serán de color verde oscuro.
- Los párrafos tendrán un tamaño de 16 px, color gris oscuro y una altura de línea de `1.5`.
- Todos los párrafos tendrán un margen inferior de 12 px.

Asocia la hoja de estilos externa al documento HTML mediante la etiqueta correspondiente dentro de `head`.

## Comprobaciones

- La hoja CSS se carga correctamente.
- Los estilos se aplican a todos los elementos del tipo correspondiente.
- Al modificar una regla de `estilos.css`, cambia la presentación de la página sin tener que modificar cada párrafo.

## Entrega

Los dos archivos y una captura del resultado.
