# Ejercicio 4. Selectores de etiqueta clase e identificador
### 1. ¿Qué diferencia existe entre un selector de etiqueta y uno de clase?

Respuesta: El de etiqueta aplica estilos a todos los elementos de ese tipo y el selector de clase solo a los que tienen  esa clase

### 2. ¿Puede utilizarse una misma clase en varios elementos?

Respuesta: Sí, una misma clase puede usarse en varios HTML para reusar código y estilos

### 3. ¿Puede un elemento tener dos clases al mismo tiempo? Demuéstralo en el código.

Respuesta: Sí, un elemento puede tener varias clases a la vez, se escriben en class =" ... ..." separadas con un espacio

### 4. ¿Qué diferencia hay entre seleccionar mediante clase y mediante identificador?

Respuesta: Un selector de clase se escribe con punto y puede usarse en varios HTML, pero un id es con almohadilla y será único dentro de la página
