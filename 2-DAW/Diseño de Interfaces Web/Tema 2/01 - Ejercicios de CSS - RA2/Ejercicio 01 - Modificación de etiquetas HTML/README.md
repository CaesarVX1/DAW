# Ejercicio 1. Modificación de etiquetas HTML

## Enunciado

Crea un archivo llamado `ejercicio1.html` que contenga un título principal, dos subtítulos y tres párrafos sobre un tema de tu elección.

Aplica las siguientes modificaciones:

- El primer párrafo debe aparecer en color rojo y en negrita.
- El segundo párrafo debe tener un tamaño de letra de 20 px.
- El tercer párrafo debe aparecer en color verde y alineado al centro.
- El título principal debe tener un fondo azul y texto blanco.
- El primer subtítulo debe aparecer en color naranja.

Realiza estas modificaciones utilizando el atributo `style` de las etiquetas HTML.

## Comprobaciones

- Cada elemento tiene el aspecto solicitado.
- Los estilos solo afectan a los elementos que has modificado.
- El documento sigue mostrando correctamente su contenido.

## Entrega

Archivo HTML y captura de pantalla del resultado.
