# Ejercicio 10. Mejora y mantenimiento de una interfaz


## Respuestas y comprobaciones

### 1. ¿Qué ventajas tiene separar HTML de CSS?

Respuesta: Deja todo más organizado y limpio para luego cambiar el diseño de la página sin tocar el HTML

### 2. ¿Qué cambios has podido realizar sin modificar el HTML?

Respuesta: He podido cambiar los colores, márgenes, rellenos, bordes, aspecto de tarjetas y botones con el CSS

### 3. ¿Qué problemas aparecen al repetir declaraciones de estilo?

Respuesta: El código se hace más largo y se queda más desordenado y es más fácil liarla ya que cometerías errores más rápido

### 4. ¿Qué aporta una clase frente a estilos individuales?

Respuesta: Te deja reusar el estilo en varios elementos sin repetir código
