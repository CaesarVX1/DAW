## Respuestas y comprobaciones

### 1. Cambia el relleno de 15 px a 30 px. ¿Qué cambia?

Respuesta: Aumenta el espacio interior de las tarjetas, se ven más grandes y está menos pegado a la parte del extremo

### 2. Cambia el margen de 10 px a 25 px. ¿Qué cambia?

Respuesta: Aumenta el espacio exterior de alrededor de la tarjeta, se queda más separada de los otros elementos

### 3. Elimina temporalmente el borde. ¿Cómo cambia la apariencia?

Respuesta: Pierdel a línea gris que los rodea, cuesta distinguir donde termina cada tarjeta y donde queda el fondo o donde acaba

### 4. Modifica el ancho y explica cómo afecta al espacio ocupado.

Respuesta: Cambia el espacio horizontal que ocupa cada tarjeta, si se aumenta las tarjetas son más fgrandes y ocupan más espacio, si se reduce, son más estrechas
