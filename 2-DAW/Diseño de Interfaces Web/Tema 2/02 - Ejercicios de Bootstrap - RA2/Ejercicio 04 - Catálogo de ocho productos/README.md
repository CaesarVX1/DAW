# Ejercicio 4. Catálogo de productos responsive con conmutador de temas

Israel · Revisado directamente en Moodle el 2 de noviembre de 2026.

[Enunciado original](https://aulavirtual.murciaeduca.es/mod/assign/view.php?id=1536670) · Cierre: 6 de noviembre de 2026, 00:00.

## Requisitos actuales

- [ ] Presenta ocho productos con imagen, nombre, precio en € y botón «Añadir al carrito»; usa un elemento HTML para separar cada producto del resto.
- [ ] Añade una barra de búsqueda y filtros visuales.
- [ ] Añade el nombre de la tienda, enlaces de navegación con nav y un icono o botón de carrito.
- [ ] Haz que el menú se pliegue en pantallas pequeñas.
- [ ] Muestra insignias como «Oferta», «Nuevo» o «Agotado».
- [ ] Desactiva el botón de los productos agotados.
- [ ] Usa una alerta para confirmar que se añadió un producto.

El título de Moodle menciona un conmutador de temas; el desarrollo del ejercicio describe los requisitos anteriores. Consulta al profesor si también lo exige aquí.

## Código de partida

index.html incluye el botón de carrito del enunciado actual. El catálogo y su comportamiento quedan pendientes.
