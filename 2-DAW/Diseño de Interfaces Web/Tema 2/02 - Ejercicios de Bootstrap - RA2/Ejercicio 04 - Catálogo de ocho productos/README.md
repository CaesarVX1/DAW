# Ejercicio 4. Catálogo de ocho productos

## Enunciado

- Muestra ocho productos con imagen, nombre, precio en euros y botón «Añadir al carrito». Separa cada producto en un `article`.
- Añade una barra de búsqueda y filtros visuales.
- Pon el nombre de la tienda, enlaces de navegación y un icono o botón de carrito. El menú debe plegarse en pantallas pequeñas.
- Usa insignias como «Oferta», «Nuevo» o «Agotado». Desactiva los botones de los agotados y muestra una alerta al añadir un producto.
