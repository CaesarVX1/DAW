# Ejercicio 3. Catálogo responsive con conmutador de temas

## Enunciado

- Crea un catálogo de cuatro productos con la rejilla de Bootstrap. Debe verse en una columna en móvil, dos en tableta y cuatro en escritorio.
- Usa `theme-light.css` por defecto y declara `theme-dark.css` como hoja alternativa. Añade un control para cambiar de tema.
