Resumen de los requisitos; consulta Moodle para el texto íntegro y los criterios de evaluación.

- [ ] Crea catálogo de cuatro productos con rejilla Bootstrap de 12 columnas.
- [ ] Usa container, row, col-12, col-md-6 y col-lg-3: una columna en móvil, dos en tableta, cuatro en escritorio.
- [ ] Crea theme-light.css por defecto y theme-dark.css alternativa con title Oscuro y rel alternate stylesheet.
- [ ] Implementa script o botones para cambiar en tiempo real y comprueba los tres tamaños.
